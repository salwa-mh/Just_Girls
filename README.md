# Just_Girls #Skincare Store

A simple front-end skincare store website developed as part of web development training using **HTML, CSS, and JavaScript**.

## Overview

This project is a basic skincare e-commerce website created to practice front-end web development concepts and build an interactive user interface for browsing skincare products.

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Documentation

* [Project Slides](Project_Presentation.pdf)
* [Project Report](Project_Report.pdf)

## Features

* Browse skincare products
* Product presentation and details
* Interactive user interface
* Basic JavaScript interactions
* Responsive front-end design

## Note

This project is a front-end training project and does not include a backend or database.
